# Housie Hour

A browser-based Housie (Tambola) game built with HTML, CSS, and JavaScript.

## Features

- Generate and call Housie numbers from 1 to 90.
- Track called numbers during a game.
- Responsive layout for desktop and mobile screens.
- Runs directly in a modern web browser without a build step.

## Run Locally

Open `index.html` in a browser, or use the VS Code Live Server extension.

## Project Files

- `index.html` - page structure
- `style.css` - visual styling and responsive layout
- `script.js` - game behavior
